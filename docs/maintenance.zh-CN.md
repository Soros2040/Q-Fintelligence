# 维护与交接

Julius 维护项目方向、审阅任务并协调发布。贡献记录为实际完成设计、实现、执行或复核的人署名；共同维护者在接受具体职责后登记。

| 职责 | 必需记录 |
| --- | --- |
| 任务分流 | Issue、范围、负责人、验收条件与依赖 |
| 技术审阅 | 来源/版本、假设、检查与未解决局限 |
| 文档维护 | 双语一致性、有效链接与可读图表 |
| 发布 | 已审阅文件清单、许可与署名、验收记录及提交 |
| 交接 | 最近可用入口、环境、下一步与待决问题 |

交接时提供最小阅读顺序，说明实际检查到哪一步。凭据留在执行环境中；说明授权协作者如何获得访问，但不要把访问细节写进公开文档。

结果变化时，同步修改来源表、两种语言及对应案例。历史结果保留所属版本。维护暂停时，记录最后支持的快照和开放任务，让下一位贡献者能够完成范围明确的改进。

[贡献指南](../CONTRIBUTING.zh-CN.md)提供记录模板。
