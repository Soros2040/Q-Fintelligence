## 研究问题

量子优化器可能十分准确地最小化了一个错误的金融目标。在比较求解器之前，收益单位、协方差期限、资产顺序、实际前持仓与持仓数量必须描述同一个决策。本案例检查这一接口。

设二元选择 $`x_i\in\lbrace 0,1\rbrace `$ 且 $`\sum_i x_i=K`$，等权持仓为 $`w=x/K`$。$`\mu`$ 为预期简单收益，$`\Sigma`$ 为同期限对称协方差，$`v`$ 为实际前持仓，$`\lambda`$ 为风险系数，$`c`$ 为单位换手成本：

```math
J(x)=-\mu^Tx/K+\lambda x^T\Sigma x/K^2+c\sum_i|x_i/K-v_i|.
```

保留 $`1/K`$ 与 $`1/K^2`$ 非常关键：改变它们会改变收益与风险的权衡。现金或退出可选股票池的历史持仓同样影响前持仓核算。

## 精确变换

由于 $`x_i`$ 只有两个取值，

```math
|x_i/K-v_i|=|v_i|+x_i\left(|1/K-v_i|-|v_i|\right).
```

因此每个二元变量上的成本项都是仿射函数。若求解器遍历完整二元域，可加入 $`\kappa(\sum_i x_i-K)^2`$。采用上三角 QUBO 约定：

```math
C(x)=C_0+\sum_iQ_{ii}x_i+\sum_{i<j}Q_{ij}x_ix_j,
```

```math
Q_{ii}=-\mu_i/K+\lambda\Sigma_{ii}/K^2+c(|1/K-v_i|-|v_i|)+\kappa(1-2K),
```

```math
Q_{ij}=2\lambda\Sigma_{ij}/K^2+2\kappa,\quad C_0=c\sum_i|v_i|+\kappa K^2.
```

协方差非对角项的系数二来自对称二次型。如果使用完整对称矩阵存储，系数约定需要相应变化；直接套用会重复计算交互项。

代入 $`x_i=(1-z_i)/2`$，$`z_i\in\lbrace -1,1\rbrace `$。Ising 耦合为 $`J_{ij}=Q_{ij}/4`$，局部场为 $`h_i=-Q_{ii}/2-\sum_{j\ne i}Q_{\min(i,j),\max(i,j)}/4`$，常数为 $`C_0+\sum_iQ_{ii}/2+\sum_{i<j}Q_{ij}/4`$。常数不改变最优解，但比较能量值或目标差距时必须保留。

## 两资产手算例子

取 $`K=1`$、$`\mu=(0.02,0.01)`$、$`\Sigma=\mathrm{diag}(0.04,0.01)`$、$`\lambda=0.5`$、$`c=0.001`$，原持仓为 $`v=(1,0)`$。继续持有资产一的成本为 $`-0.02+0.5(0.04)=0`$。切换到资产二的成本为 $`-0.01+0.5(0.01)+0.001(2)=-0.003`$：卖出原持仓并买入新持仓产生两个单位的换手。

取 $`\kappa=1`$，QUBO 系数为 $`Q_{11}=-1.001`$、$`Q_{22}=-1.004`$、$`Q_{12}=2`$、$`C_0=1.001`$。代入两个可行状态，得到相同成本：$`C(1,0)=0`$、$`C(0,1)=-0.003`$。这个合成例子解释编码关系，数字不代表实际投资收益。

## 从编码目标到测量分布

令 $`H_C=\sum_x C(x)|x\rangle\langle x|`$ 为对角代价算符，一般交替线路写为：

```math
|\psi(\boldsymbol\gamma,\boldsymbol\beta)\rangle=
\prod_{\ell=1}^{p}e^{-i\beta_\ell H_M}e^{-i\gamma_\ell H_C}|\psi_0\rangle.
```

初态和混合器决定理想演化是否保持基数。可行子空间混合器即便理想地保持汉明重量，编译误差和设备噪声下仍需测量可行率。实际实验由候选配置和编译操作定义，不能只凭“QAOA”名称推断实现。

![原图：计算概率与采样频率](../../assets/original/probabilities.png)

*原本地演示：`B01_L0.1`、`qas_00`、固定 $`(\gamma,\beta)=(0.6,0.25)`$、1,024 次采样。实心柱是计算概率，空心柱是频率；整数由 `q5…q0` 位序解释。此图记录本地模拟和采样。*

设可行集合 $`\mathcal F=\lbrace x:\sum_i x_i=K\rbrace `$，测量分布为 $`p(x)`$：

```math
P_{\mathrm{feas}}=\sum_{x\in\mathcal F}p(x),\qquad
G_{\mathrm{cond}}=\frac{\sum_{x\in\mathcal F}p(x)[J(x)-J^\star]}{P_{\mathrm{feas}}}.
```

条件差距要求 $`P_{\mathrm{feas}}>0`$。同时报告二者，才能区分接受组合的质量与有用测量占比。只看最好样本会丢失这两类信息。$`N`$ 次采样中某状态频率的边缘方差为 $`p(1-p)/N`$，低概率最优态可能完全未被观察到。

![原图：三资产可行组合的概率](../../assets/original/feasible_probabilities.png)

*横轴枚举 20 个可行组合，柱高仍保留原分布概率质量，应与 64 态完整分布一起阅读。*

## E05：同时比较简单与强基线

[E05记录](../../evidence/E05.json)包含九基础日期乘三档风险系数形成的27个固定目标。主端点是深度3、4096 shots下的**条件可行期望目标差距**，先在每个目标内平均种子，再给出配对目标bootstrap与九基础日期聚类敏感性分析。

| 比较 | 平均差值 | 解读 |
|---|---:|---|
| QAOA − 均匀可行采样 | `−0.0016276387` | 优于简单采样参照 |
| QAOA − 经典局部搜索 | `+0.0024316311` | 劣于经典搜索参照 |

研究记录应同时呈现这两条结果。27个目标复用九个日期，不能视作27个无关市场样本。原图是单个本地演示，E05有自己的深度、shots、配对单位与资源量。保持身份对应，才能避免把集中的演示分布当作基准优势证明。

## 练习与答案检查

1. 为什么两资产换仓成本是 `0.002`？**检查：**一单位卖出加一单位买入。
2. 上三角交叉项2如何转对称存储？**检查：**两侧各1，二次型访问两次。
3. 接受样本几乎全最优是否足够？**检查：**还要可行率、测量数、优化开销与参照方法。
4. E05两条结论矛盾吗？**检查：**比较对象不同，可以优于均匀而劣于局部搜索。
5. 创建Issue检查一条 `paired_units` 与差距定义，写明基础问题、单位和方向。阅读既有记录不要求重跑实验。

## 边界与下一实验

惩罚强度应超过违反约束可能获得的相关目标改善。应记录推导并检查不可行状态，而不是使用没有解释的大数。金融评价还要在每次资产重排后保持身份，并按相同执行假设比较真实交易成本。

一项有价值的贡献是加入一个受阻历史持仓和明确现金项。验收要求是在每个允许状态上直接目标与编码目标一致，并说明哪些持仓固定。该扩展属于后续工作；当前公开示例使用等权固定基数设定。
