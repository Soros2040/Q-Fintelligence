# 案例 02 · 量子局部表征与经典参照

[English](02-representations.md) · [研究地图](../research_zh.md) · [Notebook](../../notebooks/02_representation_evidence.ipynb)

## 可检验的贡献

量子特征映射将小型向量转换为可观测特征，可以与经典图聚合和可学习预测头组合。需要检验的是：该表征能否以可接受成本改善一个明确的留出任务。比较必须使用相同输入信息、标签、日期划分和模型选择预算。

项目将完整资产图保留在经典内存中，以小型局部量子寄存器计算特征。因此图规模和量子寄存器规模表示不同资源。跨资产、日期、训练迭代与候选映射的调用都需要计入成本。

## 信息时钟与设计

2.1.0 的[规范化面板](../../algorithm/qf_algorithm/data.py)为每个标签记录可用日期。在其下一开盘到随后开盘的收益任务中，退出开盘之前标签尚不可知。[方法链](../../algorithm/qf_algorithm/pipeline.py)只纳入评价开始前已成熟的训练标签，并只用训练行拟合标准化参数。

未来风险目标同样需要这一合同：将五期未来标签向后移动一个日期，并不会让它立即可见。历史实验应保留原有身份与局限。更新信息合同并不等于重新运行了历史比较。

识别均值表征的作用时，应固定协方差估计器；识别风险估计时，应固定均值估计器；研究图方向时，应在同任务下比较方向图、反向图、自连接和随机结构。若多个比较构成预先定义的比较族，应同时检查多重校正和重采样单位。

## 分别阅读两个任务

| 字段 | E02 映射 | E03 局部消息 |
|---|---|---|
| 标签 | 五期未来下行风险，原年化尺度 | 登记的下一开盘股票收益任务 |
| 观测 | 576 日期、3,456 个资产日期对、5 种子 | 485 个共同日期、5 种子 |
| 主要比较 | 选定映射减经典映射 | 局部消息减验证期选定的经典图模型 |
| MAE 差 | `−0.0005830381` | `+0.0000883367` |
| 归档 95% 区间 | `[−0.0009172197, −0.0002712622]` | `[0.0000409374, 0.0001486703]` |
| 解释 | 该任务上选定量子特征的误差更低 | 该任务上量子局部消息模型误差更高 |

[E02](../../evidence/E02.json)和 [E03](../../evidence/E03.json)保留配对平稳时间区组设置和种子聚合方式。E02 的选定与固定映射得到相同终点；E03 的选定与固定方向实现也在归档输出中重合。这些观察限制了架构选择可以获得的贡献归因。

## 从预测到组合

预测变化会影响排序、换手与尾部损失。E07 完整方法比较保持记录中的交易假设和成本 `0.001`：完整方法的种子平均 CVaR95 为 `0.0369492238`，经典为 `0.0275373056`，完整减经典为 `+0.0094119182`，归档 95% 区间 `[0.0059764443, 0.0133643372]`。损失终点越低越好。完整方法与固定映射结果相同。

[公开 E07 汇总](../../evidence/E07.json)记录 485 个区间与 5 个种子。允许分数持仓、只做多、复权价格和执行代理等假设定义了结果范围；该记录不等同于实盘投资业绩。

## 源码与后续验证

依次阅读[图学习头](../../algorithm/qf_algorithm/legacy/graph_head.py)、[特征计算](../../algorithm/qf_algorithm/legacy/quantum_features.py)、[风险估计](../../algorithm/qf_algorithm/risk.py)和[方法链](../../algorithm/qf_algorithm/pipeline.py)。Notebook读取公开汇总并检查比较差值，不重新训练模型或重算时间区组区间。

下一项有价值的实验是：在同一标签、成熟标签规则、相同留出日期和固定风险估计下，配对控制模型容量与成本，记录特征、训练和搜索时间。应公开所有预定义比较，并解释选定映射为何与固定候选相同。只有把特征层改善传递到组合终点后，才能讨论金融价值。
