# 研究地图

[English](research.md) · [首页](../README_zh.md)

核心问题是：在计入数据时钟、强经典参照和完整计算成本之后，量子组件能否提供有用的信息或搜索质量。项目区分金融预测、组合决策与物理线路行为三个输出。一个层次的改善不会自动传递到另外两个层次。

## 前置知识与学习路线

1. 学习训练/验证/测试划分、标签可用时间与配对比较。
2. 阅读均值—方差目标、固定持仓数量、交易成本和协方差半正定性。
3. 完成二元变量到 Ising 的代换，以及可行组合上的概率分布分析。
4. 理解局部量子特征、图聚合、参数学习与线路编译。
5. 检查有限测量波动、噪声模型与配对硬件分析。

小型教学示例只要求 Python 与基础线性代数；深入源码还会涉及 TypeScript、React、SQLite、Python 数值计算和 Linux 进程隔离。

## 深入案例

- [01 · 目标 → QUBO → Ising](cases/01-objective_zh.md)：推导精确交易成本项、保持尺度并逐态枚举。
- [02 · 量子局部表征与经典参照](cases/02-representations_zh.md)：对齐信息时钟、区分任务终点，解释有利及不利效应。

每个案例都提供 Notebook、源码入口、结果与下一实验。下一实验属于研究提议，不作为完成进度。

## 下一轮研究的组织方式

冻结共同数据/标签合同；只用开发数据选择模型和线路设置；记录特征、训练、搜索与测量成本；在留出日期评价，报告配对效应与不确定性；随后只将冻结线路迁移至硬件。比较选择方法时保持同一候选池和搜索预算。先用各组件自己的终点判断其作用，再讨论对组合表现的贡献。
