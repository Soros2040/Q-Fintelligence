# 研究地图

[English](research.md) · [首页](../README_zh.md)

核心问题是：在计入数据时钟、强经典参照和完整计算成本之后，量子组件能否提供有用的信息或搜索质量。项目区分金融预测、组合决策与物理线路行为三个输出。一个层次的改善不会自动传递到另外两个层次。

## 研究方向与源码锚点

持续研究的重点是量子计算与 QML。金融任务提供具体基准，工作台是组织研究的支撑设施。下列三条已有源码路径组织后续问题，新的狭窄课题将在研究讨论中确定。

| 路径 | 已有数学对象 | 源码与证据 | 开放问题 |
|---|---|---|---|
| 量子表示 | 保真度核与局部 Z/ZZ 特征 | [特征源码](../algorithm/qf_algorithm/legacy/quantum_features.py)、[E02 实现](../algorithm/qf_algorithm/legacy/run_e02.py)、E02/E03 | 哪种任务感知表示或核设计规则经得起匹配经典与资源控制？ |
| 约束优化 | 二元目标、QUBO、Ising 与可行输出分布 | [Bridge](../algorithm/qf_algorithm/legacy/bridge.py)、E01/E05 | 可行质量如何扩展，所需搜索/测量预算多大？ |
| 硬件感知选择 | 候选代理与配对分布指标 | [Selection](../algorithm/qf_algorithm/selection.py)、E06、硬件/云端 | 哪些选择准则能泛化到留出问题与独立校准？ |

E02 已有核实现：12 个冻结映射、32 个训练锚点与共享经典预测头。一般性的量子核自设计方法仍是可能的研究扩展。[案例 02](cases/02-representations_zh.md)区分这些主张与资源模型。

## 前置知识与学习路线

1. 学习训练/验证/测试划分、标签可用时间与配对比较。
2. 阅读均值—方差目标、固定持仓数量、交易成本和协方差半正定性。
3. 完成二元变量到 Ising 的代换，以及可行组合上的概率分布分析。
4. 理解保真度核、局部量子可观测量、图聚合、参数学习与线路编译。
5. 检查有限测量波动、噪声模型与配对硬件分析。

小型教学示例只要求 Python 与基础线性代数；深入源码还会涉及 TypeScript、React、SQLite、Python 数值计算和 Linux 进程隔离。

## 深入案例

- [01 · 目标 → QUBO → Ising](cases/01-objective_zh.md)：推导精确交易成本项、保持尺度并逐态枚举。
- [02 · 保真度核与局部特征](cases/02-representations_zh.md)：对齐信息时钟、区分任务终点，解释有利及不利效应。
- [03 · 候选选择与硬件迁移](cases/03-hardware_zh.md)：在一次校准条件下比较理想、有限测量、本地含噪、云端含噪与硬件记录。

每个案例包含公式、源码入口、逐字节复制的原图、配套 Notebook、结果、局限及阅读/贡献任务。下一实验属于研究提议，不作为完成进度。

## 下一轮研究的组织方式

冻结共同数据/标签合同；只用开发数据选择模型和线路设置；记录特征、训练、搜索与测量成本；在留出日期评价，报告配对效应与不确定性；随后只将冻结线路迁移至硬件。比较选择方法时保持同一候选池和搜索预算。先用各组件自己的终点判断其作用，再讨论对组合表现的贡献。
