# QF Algorithm 2.1.0

[中文](README_zh.md) · [Home](../README.md) · [Environment and commands](../docs/reproduction.md)

Python source for a local data → graph/risk → portfolio objective → candidate-circuit method chain. The [CLI](qf_algorithm/cli.py) delegates to a common API and records mode, configuration and artifacts. The package requires Python 3.11.

Read [architecture](../docs/architecture.md), [objective case](../docs/cases/01-objective.md) and [installation](../docs/reproduction.md#3-algorithm-package). Root teaching examples are lightweight; the full package has scientific dependencies and may fit local models.

Compatibility commands require separately authorized historical inputs and archive layout. Curated public evidence is not a substitute for that archive. Dependency installation and full method-chain execution are separate tasks in [status](../docs/status.md).
