# 完整贡献记录示例：核对一条来源链接

这份填写完整的教学示例演示记录格式，来源为本仓库的贡献指南。示例尚未关联真实 Issue、指定审阅者或已合并 PR。

| 字段 | 示例填写 |
| --- | --- |
| 标题 | 核对“已接受贡献”的含义 |
| Issue 与约定范围 | 教学示例；复核一句表述及其来源 |
| 作者与实际贡献 | 示例贡献者：来源阅读与文字复核 |
| 来源与准确位置 | [贡献指南](../CONTRIBUTING.zh-CN.md)，“从 Issue 到已接受的贡献”第 5–6 步 |
| 版本 | 与本示例属于同一仓库版本的指南；真实复核时替换为固定提交链接 |
| 待核查表述 | 一项任务经审阅并合并后成为已接受贡献 |
| 实际检查 | 阅读第 5–6 步，比较其顺序与贡献记录字段 |
| 发现 | 支持：先审阅、再合并，然后登记审阅者和已合并的 PR/提交 |
| 修改建议 | 任务记录中分别使用“开放”“已认领”“已接受”状态 |
| 双语更新 | 配套英文示例采用相同状态与来源位置 |
| 审阅者 / 决定 | 真实贡献中等待审阅后填写 |
| 已合并 PR / 提交 | 教学示例暂未分配 |
| 剩余问题 | 任务负责人需补充真实 Issue 与审阅结果 |

## 将格式用于研究表述

从案例中选择一句话，把示例来源替换为准确公式、表格行或函数。涉及数字时记录数据区间与比较对象。若来源只支持句子的一部分，提出范围更准确的写法，并说明还缺哪些证据。随后按[贡献流程](../CONTRIBUTING.zh-CN.md)提交记录与聚焦的 PR。
