# Worked contribution record: checking a source link

This completed teaching example demonstrates the record format. It uses the contribution guide in this repository as its source. There is no live Issue, assigned reviewer or merged PR associated with the example.

| Field | Example entry |
| --- | --- |
| Title | Verify the meaning of “accepted contribution” |
| Issue and agreed scope | Teaching example; review one sentence and its source |
| Author and actual contribution | Example contributor: source reading and wording review |
| Source and exact location | [Contribution guide](../CONTRIBUTING.md), “From an Issue to an accepted contribution”, steps 5–6 |
| Version | The copy of the guide in the same repository revision as this example; for a real review, replace this with a commit permalink |
| Claim under review | A task becomes an accepted contribution after review and merge |
| Check performed | Read steps 5–6 and compare the stated sequence with the contribution record fields |
| Finding | Supported: review precedes merge, and the record then receives the reviewer and merged PR/commit |
| Suggested change | Keep “open”, “claimed” and “accepted” as separate states in task records |
| Bilingual update | The paired example uses the same states and source locations |
| Reviewer / decision | Awaiting review in a real contribution |
| Merged PR / commit | Unassigned in this teaching example |
| Remaining question | The task owner must provide the real Issue and review outcome |

## Apply it to a research claim

Choose a sentence in a case study. Replace the example source with the exact equation, table row or function. Record the data window and comparison when numbers are involved. If the source supports only part of the sentence, propose narrower wording and explain what evidence is still needed. Then submit the record with a focused PR through the [contribution workflow](../CONTRIBUTING.md).
