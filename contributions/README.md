# Contribution records / 贡献记录

Add one Markdown record per reviewed contribution using the [English template](../CONTRIBUTING.md#contribution-record) or [中文模板](../CONTRIBUTING.zh-CN.md#contribution-record). Link the Issue, sources, actual checks and merged PR/commit. This directory starts as an open contribution register; no external acceptance or reviewer is implied by its creation.

每项经审阅的贡献建立一份记录，关联 Issue、来源、实际检查及合并的 PR/提交。本目录是开放的贡献登记入口，创建目录本身不代表已取得外部审阅或认可。

See the [worked example](example-review.md) / [完整示例](example-review.zh-CN.md).
